
# ♻️ Aprende a reciclar | EcoAprende

Plataforma educativa interactiva para aprender a clasificar residuos,
fomentar el reciclaje y promover hábitos sostenibles.

## 🌎 ¿Qué es?

Aprende a reciclar es un proyecto web que busca enseñar
educación ambiental a través de juegos, cuestionarios y
actividades interactivas.

## 🎮 Funciones

- Clasificación de residuos.
- Juego interactivo.
- Cuestionario educativo.
- Sistema de puntos.
- Diseño adaptable a computadoras y celulares.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Promover la educación ambiental y el desarrollo sostenible
mediante la tecnología.
